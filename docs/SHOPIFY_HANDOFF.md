# Shopify-overdracht
Alleen theme/ is de uploadbare theme-root. Het GitHub-project zelf bevat ook documentatie en een offline preview; verbind deze repository niet blind als volledige theme-root.

Gebruik Shopify CLI lokaal met --path theme. Test op een development store. Houd een bestaande winkel met een Shopify-wachtwoord afgeschermd; de prelaunchpagina’s blokkeren geen directe Shopify API- of checkouttoegang. Dit project wijzigt geen winkelinstellingen.

Nog nodig: development-storetoegang, Shopify CLI, logo/merknaamcontrole, echte productfoto’s en verpakkingen, goedgekeurde receptuur/ingrediënten/allergenen/voedingswaarden, prijzen incl. btw, voorraad, Starter Mix-aantallen, juridische bedrijfsgegevens, retourvoorwaarden, verzending en privacybeleid.

Er is geen nieuwsbrief-formulier of tracking: geen onbedoelde opslag van persoonsgegevens. Cart/product/collection/search/page/blog-routes tonen een neutrale prelaunchpagina. Wachtwoord-template bevat geen login-formulier; Shopify Admin blijft de route voor beheer. Commerce en eventuele wachtwoord-login-UX zijn later werk.
